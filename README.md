## 📋 Project Overview
This project was developed as a collaborative team assignment based on client design specifications, adhering strictly to core front-end standards and responsive layout best practices.

### Key Features
- **Pages**: Landing Page (Home), About Us, Contact Us.
- **Pure CSS Navigation**: Responsive hamburger menu built with pure HTML & CSS (No JavaScript).
- **Responsive Layout**: Designed and tested for mobile (375px), tablet (768px), and desktop (1200px+) viewports.
- **Strict Styling Guidelines**: Adheres to the assigned dark/accent color palette (`#1F2937`, `#3882F6`, `#F9FAF8`) and typography (Roboto font).

## 🛠️ Built With
- **HTML5**: Semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- **Vanilla CSS3**: Layout built entirely using **CSS Flexbox** and Media Queries (No CSS Grid).
- **Font Awesome**: Icons.
- **GitHub Pages**: Deployment and hosting.
